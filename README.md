About QOVYRA

QOVYRA is an intelligent technology platform designed to modernize the way Quality Engineering is learned, practiced, analyzed, and applied across industries.

It brings together Artificial Intelligence, Total Quality Management, Statistical Quality Control, Manufacturing Engineering, Reliability Engineering, and Industrial Simulation into a unified digital ecosystem.

The platform aims to bridge the gap between engineering education and real-world industrial quality practices through intelligent assistance, interactive engineering tools, virtual manufacturing environments, and data-driven learning experiences.

QOVYRA is designed for:

- Engineering Students
- Quality Engineers
- Manufacturing Professionals
- Industrial Engineers
- Researchers and Academicians
- Engineering Organizations
- Quality Management Professionals

Our Vision: To make Quality Engineering more intelligent, accessible, practical, and technology-driven.

Core Platform Modules

1. AI Quality Mentor

An AI-powered knowledge and problem-solving interface designed to support a broad range of Quality Engineering and related technical subjects.

Key capabilities include:

- Total Quality Management
- Statistical Quality Control
- Quality Assurance and Quality Control
- ISO Standards and Quality Management Systems
- FMEA, FTA, RCA, CAPA and 8D
- Six Sigma and Lean Manufacturing
- Reliability Engineering
- Manufacturing Quality
- Industrial Problem Solving
- Engineering Mathematics
- Technical and Research-Oriented Questions

The mentor is designed to support multiple learning levels:

- Beginner
- Intermediate
- Advanced
- Expert / Research Level

Additional capabilities include Quick Mode, Deep Mode, mathematical explanations, numerical problem-solving, and reference document support.

Gemini API integration is used for dynamic AI response generation.

2. Interactive 3D Virtual Factory

A real-time 3D industrial environment designed to demonstrate manufacturing processes and machine-level interactions.

Features include:

- Interactive 3D factory visualization
- Robotic manufacturing equipment
- CNC machinery
- Industrial production stations
- Machine selection
- Machine information panels
- Camera rotation
- Zoom and pan controls
- Auto-rotation
- Exploded View
- Interactive machine exploration

The objective is to provide an immersive representation of industrial manufacturing environments.

Coverage includes:

The module is designed to organize defect information, causes, detection methods, preventive measures, and corrective actions.

Getting Started

Prerequisites

Before running the project locally, ensure that you have:

- Node.js
- npm or an equivalent package manager
- Git
- A compatible modern browser
- Gemini API access for AI functionality

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the Project

cd YOUR_PROJECT_FOLDER

3. Install Dependencies

npm install

4. Configure Environment Variables

Create the required environment configuration using the project's actual backend architecture.

For a server-side Gemini integration, configure:

GEMINI_API_KEY=your_gemini_api_key

Security Notice:

- Never commit API keys to GitHub.
- Never expose private API credentials in frontend code.
- Use server-side environment variables or the supported secret-management system.
- Add local environment files to ".gitignore".
- Use the exact environment variable name expected by the application.

5. Start the Development Server

For a Vite-based project:

npm run dev

6. Build for Production

npm run build

Use the actual scripts defined in "package.json" if they differ from these examples.
